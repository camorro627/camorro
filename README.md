# 🐝 SwarmAttack Framework

**إطار اختبار اختراق عنقودي (Swarm) — يتنفس، يتخفّى، ويضرب من كل الاتجاهات**

بدل مهاجم واحد يصدر منه تدفق الطلبات من نقطة واحدة، يُطلق SwarmAttack **خلايا هجوم مستقلة** —
كل خلية = بروكسي دوّار + بصمة TLS مطفَّرة + محرك سلوك بشري — تستهلك المهام من طابور مركزي،
فتتوزع الحمولة على أيدي كثيرة لا يمكن ربطها ببعضها.

> **من إنشاء: Yassine — الملقب بـ Camorro**

---

**Python 3.10+** • **Linux (Kali) / Termux (Android)** • **متوافق مع الاثنين بنفس الشيفرة**

## 🧠 المقدمة

SwarmAttack هو إطار **اختبار اختراق تطبيقات الويب** مصمم للهروب من الكشف عبر توزيع الهجوم:

| المشكلة في الأدوات التقليدية | الحل في SwarmAttack |
|---|---|
| كل الطلبات تصدر من IP واحد | شبكة بروكسيات دوّارة مع دوائر لزجة |
| بصمة TLS ثابتة تُكشف بسهولة | تزوير بصمة JA4 على مستوى الحزمة لكل خلية |
| أنماط طلبات آلية واضحة | محرك سلوك بشري: تأخيرات، تفكير، تذبذب |
| نقطة فشل واحدة | خلايا مستقلة مع دائرة كهربائية وشفاء ذاتي |

> ⚠️ **ترخيص الاستخدام**: أداة مخصصة لاختبارات الاختراق **المأذون بها** فقط (أنظمتك الخاصة،
> أو أهداف ضمن نطاق عقد اختبار اختراق موقّع). الاستخدام ضد أطراف ثالثة دون إذن قانوني
> يعرّضك للمساءلة — أنت المسؤول الوحيد عن الاستخدام.

## ✨ المميزات

*   **خلايا هجوم مستقلة** بعدد قابل للضبط، مع دائرة كهربائية (circuit breaker) وشفاء ذاتي:
    كل خلية تراقب إخفاقاتها، وعند تجاوز الحد تعيد تدوير بروكسيها وتدخل فترة تهدئة تلقائياً.
*   **تزوير بصمة TLS (JA4)** على مستوى الحزمة + إثبات ذاتي (`--self-test`):
    بناء ClientHello حقيقي المظهر من بروفايلات Chrome/Firefox/Safari/Edge مع حساب بصمة JA4
    والتأكد أن ما يُبنى على الشبكة = ما يُحسب نظرياً.
*   **شبكة بروكسي دوّارة** مع دوائر لزجة (sticky circuits)، فحص صحي، وعقوبات تلقائية للبروكسيات الميتة.
*   **محركات حقن**:
    *   `sql` — خطأ / منطقي / زمني مع تمويه الحمولات وكشف WAF.
    *   `xss` — انعكاس متعدد السياقات + حمولة polyglot + DOM اختياري عبر Playwright.
    *   `bola` — كسر IDOR بالجوار الرقمي ومقارنة متجهية للاستجابات.
*   **زحف ذكي**: robots/sitemap + استخراج الروابط + تخمين المسارات + تحليل JS لاستخراج
    الأسرار (AWS keys, JWT, tokens...) والنقاط الجديدة وتغذية محركات الحقن منها.
*   **حالة مشفرة**: كل النتائج تُخزَّن AES-256-GCM (SQLite غير متزامن) مع سلسلة تكامل (hash chain).
*   **تقارير**: JSON مشفّر + Markdown قابل للقراءة.
*   **لوحة تحكم حية** (Rich) تعمل حتى بدون TTY.
*   **توافقية كاملة Termux/Linux**: نفس الشيفرة تعمل على Kali وAndroid مع ضبط تلقائي
    لعدد الخلايا والذاكرة حسب البيئة.

- كل طلب يحمل بصمة TLS وبروكسي وسلوكاً مختلفاً عن سابقه.

## 📋 المتطلبات

| المتطلب | الحد الأدنى |
| --- | --- |
| Python | 3.10+ |
| نظام التشغيل | Linux (يُفضَّل Kali) / Termux (أندرويد) / macOS / Windows |
| الذاكرة | 512MB+ (يُنصح بـ 2GB على Termux) |
| صلاحيات | root فقط لـ `--capture-profile` (يلزم scapy) |
| الشبكة | اتصال إنترنت مستقر — ويفضَّل ملف بروكسيات للهجمات المكثفة |

### الحزم

| الحزمة | الدور | على Termux |
|---|---|---|
| `curl_cffi` | تقليد بصمة TLS كاملة (JA3/JA4/H2) | ✅ تعمل |
| `aiohttp` | فحوص صحة البروكسيات غير المتزامنة | ✅ تعمل |
| `cryptography` | AES-256-GCM / ChaCha20-Poly1305 / Argon2id | ✅ تعمل |
| `aiosqlite` | قاعدة الحالة (SQLite غير متزامن) | ✅ تعمل |
| `PyYAML` | تحميل سياسات الهجوم | ✅ تعمل |
| `rich` | لوحة التحكم الحية | ✅ تعمل |
| `scapy` *(اختياري)* | `--capture-profile` فقط | ⚠️ `pkg install python-scapy` + root |
| `playwright` *(اختياري)* | فحص DOM XSS فقط | ❌ غير مدعوم — يُتخطَّى تلقائياً |

الوسيط	الوصف
--target, -t	الهدف — يُكرر لعدة أهداف (إلزامي)
--cells, -c	عدد الخلايا (يتجاوز قيمة السياسة)
--tests	فاصلة: sql,xss,bola
--policy-file	مسار YAML بديل لسياسة الهجوم
--proxy-file	ملف بروكسيات (سطر لكل بروكسي: http://… أو socks5://…)
--no-dashboard	تعطيل لوحة التحكم الحية
--self-test	اختبار محرك JA4 ثم الخروج
--capture-profile IFACE	التقاط ClientHello حقيقي من واجهة شبكة (scapy)
الاستراتيجية	الوصف
error	حمولات تُحدث أخطاء SQL تُعكس في الاستجابة
boolean	مقارنة استجابات صحيح/خطأ لاستنتاج الثغرة
time	حقن تأخير زمني (SLEEP/BENCHMARK) لكشف الحقن الصامت
المصدر	التفاصيل
robots.txt وsitemap.xml	استخراج المسارات المسموحة والممنوعة
استخراج الروابط	تحليل href في الصفحات مع تقييد بالنطاق والامتدادات
تخمين المسارات	قائمة مسارات شائعة: admin/، api/، .env، graphql، swagger...
التقييم (score)	ترتيب النقاط حسب وجود بارامترات/كلمات حساسة لتغذية الأولوية
